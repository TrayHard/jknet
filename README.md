# JKNet

JKNet — лаунчер мультиплеера Star Wars Jedi Knight: Jedi Academy для Windows. Он ставит и запускает клиенты, хранит библиотеку pk3-файлов и показывает список серверов. Steam не нужен: лаунчер только читает `base\assets0.pk3`–`assets3.pk3` из вашей копии игры и никогда не пишет в папку игры.

Состояние: каркас. Работает экран **Clients**, остальные экраны — заготовки. Запуск игры, браузер серверов и библиотека появятся в следующих задачах.

## Возможности каркаса

- Поиск папки `GameData` в установках Steam и GOG, выбор папки вручную.
- Создание, удаление и назначение клиента по умолчанию. Клиент — именованный экземпляр движка со своими файлами и настройками.
- Реестр движков: OpenJK, EternalJK, TaystJK, jaMME.
- Оболочка приложения: свой заголовок окна, боковая панель, семь маршрутов.

## Перед началом

Установите:

- Node.js 24 и npm 11;
- Rust stable с целью `x86_64-pc-windows-msvc` (`rustup default stable-msvc`);
- Visual Studio Build Tools 2022 с рабочей нагрузкой **Desktop development with C++**;
- WebView2 Runtime (Windows 11 содержит его по умолчанию).

## Быстрый старт

1. Установите зависимости фронтенда:
   ```bash
   npm install
   ```
2. Запустите приложение в режиме разработки:
   ```bash
   npm run tauri dev
   ```
   Команда поднимает Vite на порту 1420 и собирает Rust-ядро. Первая сборка занимает несколько минут.

   Чтобы посмотреть только вёрстку, выполните `npm run dev` и откройте `http://localhost:1420/` в браузере. Ядро в этом режиме не собирается: команды отвечают ошибкой `Tauri runtime is not available`, экраны показывают пустые состояния.
3. Соберите установщик:
   ```bash
   npm run tauri build
   ```
   Результат — NSIS-установщик в `src-tauri/target/release/bundle/nsis/`.

## Проверки

| Задача | Команда |
| --- | --- |
| Типы и сборка фронтенда | `npm run build` |
| Только типы | `npm run typecheck` |
| Компиляция ядра | `cargo check --all-targets` в `src-tauri` |
| Линтер Rust | `cargo clippy --all-targets -- -D warnings` в `src-tauri` |
| Модульные тесты Rust | `cargo test` в `src-tauri` |

## Где лежат данные

Лаунчер создаёт `%LOCALAPPDATA%\JKNet`:

| Путь | Содержимое |
| --- | --- |
| `settings.json` | настройки лаунчера |
| `clients\<slug>\` | клиент: `client.json`, папка `engine\`, папка `home\` |
| `library\` | скачанные pk3-файлы |
| `cache\` | списки серверов и ответы JKHub |
| `logs\` | журналы работы |

Настройка `dataDirOverride` переносит `clients`, `library`, `cache` и `logs` в другую папку. Файл `settings.json` остаётся в `%LOCALAPPDATA%\JKNet`.
